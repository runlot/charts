Helm repository

runlot on your own cluster.

This host is the Helm chart index for runlot. It serves index.yaml and one packaged chart per release, and nothing else. The chart installs the control plane into your Kubernetes cluster; the data nodes stay on machines you own.

Add the repository

Every runlot release is a release candidate today, so --devel is needed to see them.

$ helm repo add runlot https://charts.runlot.io
$ helm repo update
$ helm search repo runlot --devel
$ helm install runlot runlot/runlot --devel \
    -n runlot --create-namespace -f values.yaml

A licence is required. The chart refuses to install without the Secret that holds your licence file, and without the master key you generate — we keep no copy of either. The licence is a signed file we issue per installation; it is checked offline and never calls home.

To get one, write to hello@runlot.io. An evaluation licence is free for 90 days on a single machine.

What the chart needs

Kubernetes
1.30 or newer
Licence
a Secret with the file we issued
Master key
a Secret you create with openssl rand -hex 32
PostgreSQL
18, yours, reachable from the cluster
Object store
any S3-compatible bucket you run
Data nodes
VMs with the runlot-node package

The full install, including values.yaml and the node join, is in the self-hosted docs. The annotated values file is inside the package:

$ helm show values runlot/runlot --devel
index.yaml chart version = runlot tag
