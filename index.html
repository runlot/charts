runlot Helm charts

This is the Helm chart index for runlot. There is nothing to browse here; it exists for helm.

helm repo add runlot https://charts.runlot.io
helm repo update
helm search repo runlot --devel
helm install runlot runlot/runlot --devel -n runlot --create-namespace -f values.yaml

The install guide is at docs.runlot.io/docs/self-hosted. The chart's source is charts/runlot in the runlot repository, and the files in this index are the same bytes attached to each release.
